# Concord

Concord помогает аналитику найти одних и тех же людей или организации в двух базах. Вы выбираете таблицы и ID, проверяете предложенные поля и запускаете сопоставление. Для каждого кандидата видно, какие исходные значения совпали, где возникло расхождение и как сложился итоговый балл.

Приложение работает локально с PostgreSQL, MySQL, SQLite и файлами JSONL. Если у записи несколько кандидатов, их можно сравнить рядом и подтвердить несколько связей. Принятые пары выгружаются в CSV с обоими ID и основанием решения.

## Быстрый запуск

Из корня проекта запустите пример с вымышленными записями. Достаточно Python 3.10+ со стандартным модулем SQLite.

```sh
mkdir -p local-runs/demo
python3 -m concord --rules examples/rules.json --left examples/left.jsonl --right examples/right.jsonl --output local-runs/demo/result.jsonl
python3 -m concord.viewer local-runs/demo/result.jsonl
```

Откройте [Concord в браузере](http://127.0.0.1:8765/) и выберите «Возможные совпадения». Чтобы вернуться к сохранённому результату, повторите последнюю команду.
